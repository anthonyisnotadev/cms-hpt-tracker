The pointer file

/cms-hpt.txt is a small text file that tells software where a hospital's full price file lives.

Rule 45 CFR 180.50(d)(6)
Required Since 2024
Fields 5 per location

On this page

Purpose

A standard signpost for price files

A hospital's price file may sit on its own website, a health system website, or a vendor's server. The pointer gives every site one predictable place to publish the correct link.

Websites hosting hospital price files have been required to publish /cms-hpt.txt since January 2024. The address sits at the root of the domain, alongside familiar files such as /robots.txt.

Plain answer

The pointer is not the price data. It is a short directory that leads to the price data.

Format

Five fields for each hospital

location-name: Example Hospital
source-page-url: https://example.org/prices
mrf-url: https://example.org/charges.csv
contact-name: Price Transparency Team
contact-email: prices@example.org
Location name

The hospital or campus covered by the entry.

Source page

The human-readable webpage where the hospital publishes price information.

MRF URL

The direct link to the downloadable price file.

Contact

A name and email address for questions about the file.

Blank lines separate entries when a pointer lists more than one hospital.

Health systems

One pointer can list many hospitals

Health systems often publish one pointer file for an entire group. Each hospital or location receives its own entry.

Different locations may link to separate price files. Locations that share the same charges may point to the same file. When a vendor hosts the download, the pointer still belongs on the hospital or health system domain.

The location name matters because it connects a system-level file to an individual hospital in the CMS registry. Weak or ambiguous names may require manual review.

This tracker

How the tracker uses the pointer

The pointer turns a website search into a short, repeatable check.

1 — Request

Open /cms-hpt.txt on the hospital's known domain.

2 — Match

Find the entry that names the hospital or location.

3 — Follow

Open the listed price file and read its header.

4 — Record

Save the template version, update date, and access result.

A website that refuses the request is marked blocked, not failing. A hospital with no known website is marked not assessed. Neither group is included in the compliance rate.
