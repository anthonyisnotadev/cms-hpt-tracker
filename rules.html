The CMS rules

Most hospitals must publish a complete data file and a patient-friendly way to view common prices. The two requirements are separate.

Rule 45 CFR Part 180
In force Since 2021
Update cycle Yearly

Who

Most US hospitals are covered

The rule applies to institutions licensed as hospitals by a state. Participation in Medicare is not the deciding factor.

Federally owned hospitals, including Department of Veterans Affairs and military facilities, are treated as compliant without filing under this rule. Indian Health Service facilities and certain tribal hospitals also receive special treatment.

The CMS hospital registry provides the names and identifiers used by this tracker. That source can lag behind closures, mergers, ownership changes, and new websites.

What

Hospitals have two duties

One requirement is built for software. The other is built for patients. Passing one does not mean the other has been met.

Complete data file

A CSV or JSON file containing standard charges for hospital items and services, including rates for individual insurance plans.

Common services

A readable list or price estimator covering at least 300 services that can usually be scheduled in advance.

The patient-facing requirement includes plain descriptions and prices that can be searched without an account. The large data file is more complete, but it is not designed for casual browsing.

Access

The data file must be easy to get

Public access means more than placing a file somewhere on a website.

No gate

No login, fee, personal information, or agreement to terms before download.

Direct link

The hospital website must link to the file and make it available to automated downloads.

Pointer file

/cms-hpt.txt must identify the hospital and provide the direct file URL.

Current format

The file must use CSV or JSON and follow the current CMS template.

Updates and enforcement

Update yearly and fix problems CMS identifies

The price file must be updated at least once every 12 months. The file itself carries the date of its latest update.

CMS can review complaints, inspect a hospital's published material, and request a corrective action plan. Continued problems can lead to a daily civil penalty. The amount depends partly on hospital size and may be adjusted for inflation.

Only CMS determines violations.

A tracker finding records what an outside check observed. It is not an enforcement action or proof that a fine applies.

This tracker

What the tracker checks

The automated audit covers the parts of the rule visible from outside a hospital website.

The check asks whether the pointer opens, whether it leads to a price file, whether that file can be read, whether the template version is current, and whether the stated update date is within one year.

The patient-facing price tool is not checked. Individual rates, billing codes, completeness, and accuracy are also outside the audit. A “compliant” label means only that the published file passed this narrower set of checks.
