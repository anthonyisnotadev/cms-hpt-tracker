What it does

Turn a sentence into an outreach update

The tracker keeps outreach notes beside each hospital record. The skill provides a quicker way to update that log from a coding assistant.

A normal sentence can record an email, a reply, a follow-up date, a research note, or a correction to the crawl. Hospital names are matched against the CMS list, so internal identifiers are usually unnecessary.

The same records appear in the tracker's hospital drawer. A public export can be generated without exposing the private working file.

Workflow

You approve every change

The assistant prepares the change, but the command-line tool controls what can be saved.

Describe

State what happened in ordinary language, with a city or state when the name is ambiguous.

Match

The tool searches the hospital list and reports the match and confidence.

Preview

A dry run shows every field that would change. Nothing is written at this stage.

Approve

Saving begins only after explicit approval. The updated record is checked before completion.

Setup

Use the copy included in this repository

The skill is part of the repository. No separate service or account is required.

The instructions live in .claude/skills/outreach/SKILL.md. Assistants that support the shared Agent Skills format can read the same instructions from .agents/skills/.

The underlying tool also works directly from the terminal through npm run outreach. This route provides the same matching, preview, backup, and validation steps without an AI assistant.

Examples

Say what happened normally

Emailed Springfield Regional about its dead file link. The email bounced.
Mercy replied with a new price-file URL. Follow up next Friday.
Add a note that the hospital website now redirects to its parent system.

Short statements are enough when the hospital name is unique. Include the city, state, or CMS certification number when several hospitals share a name.

Raw replies can also be pasted into the request. The preview should be checked carefully before saving, especially when a message mentions several facilities.

Safety

The assistant proposes; the tool checks

The skill cannot silently edit the outreach file. All writes pass through the same checked command.

Approval

No data is saved before the preview receives explicit approval.

Matching

Weak or ambiguous hospital matches stop for clarification.

Recovery

The previous file is backed up before an approved change is written.

Privacy

Private notes stay local. Public exports redact configured names and contact details.
